# Studio Core — 2030 Digital Luxury Showcase

![Studio Core Preview](https://picsum.photos/seed/aura/1200/800)

**Studio Core** is a high-end digital architecture showcase designed with a "2030 Luxury" aesthetic. It redefines the portfolio experience through technical precision, minimalist architecture, and fluid motion dynamics.

## ✨ Features

- **Infinite Card Stack**: A seamless, looping interaction model for exploring curated projects.
- **2030 Luxury Aesthetic**: A sophisticated blend of glass-morphism, deep blacks, and refined serif typography.
- **Fluid Motion**: Powered by `motion/react` for physics-based animations and immersive transitions.
- **Technical Spec Overlays**: Deep-dive into project architectures with animated technical manifests.
- **Multi-modal Navigation**: Support for touch gestures (swipe), mouse drag, and keyboard shortcuts (Arrow keys).
- **Responsive Architecture**: Optimized for ultra-wide displays down to mobile devices.

## 🛠️ Tech Stack

- **Frontend**: React 19
- **Styling**: Tailwind CSS 4.0
- **Animations**: Motion (formerly Framer Motion)
- **Icons**: Lucide React
- **Deployment**: Optimized for Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/studio-core.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/components/`: Reusable UI components.
- `src/App.tsx`: Main application logic and card stack implementation.
- `src/index.css`: Global styles and Tailwind configuration.
- `vercel.json`: Deployment configuration for Vercel.

## 🌐 Deployment

This project is ready for one-click deployment to Vercel. It includes a `vercel.json` for handling SPA routing and is configured to work with Vite's build output.
